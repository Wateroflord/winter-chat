Адрес сервера для приложения

Друзья вводят адрес на экране входа в Winter Chat. Если вы в одной сети (один Wi-Fi) — подходит адрес домашней сети.

Как подключить друзей через интернет

  1. Зайди в настройки роутера и открой (пробрось) порты на этот компьютер (—):
    ПортПротоколДля чего
  2. Если Windows спросит про брандмауэр для Winter Chat Server и livekit-server — нажми «Разрешить».
  3. Дай друзьям адрес — и код приглашения.
  4. Если у провайдера нет «белого» IP, поставь всем бесплатный VPN (Tailscale, ZeroTier или Radmin VPN) — его адрес появится в списке выше.
