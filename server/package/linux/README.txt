WINTER CHAT SERVER — сервер мессенджера для тебя и друзей
==========================================================

КАК ЗАПУСТИТЬ
1. Распакуй архив в постоянную папку, например ~/winter-chat-server
2. В терминале:   cd ~/winter-chat-server && ./start.sh
3. Открой в браузере http://localhost:8090 — там адрес сервера и код приглашения.

ЧТОБЫ РАБОТАЛ ВСЕГДА (автозапуск при включении ноутбука):
   ./install-autostart.sh          (попросит пароль sudo)
   отключить: ./uninstall-autostart.sh

ДРУЗЬЯ ЧЕРЕЗ ИНТЕРНЕТ
Открой на роутере порты на этот компьютер:
   8090 TCP  — приложение, чаты, файлы
   7881 TCP  — звонки (запасной путь)
   7882 UDP  — звонки
Если провайдер не даёт «белый» IP — поставьте всем Tailscale, ZeroTier или Radmin VPN.

СОВЕТ ДЛЯ НОУТБУКА: в настройках питания отключи сон при закрытой крышке,
иначе сервер «уснёт» вместе с ноутбуком.

ДАННЫЕ
Всё хранится в папке winter-chat-data рядом с программой. Резервная копия = копия этой папки.
