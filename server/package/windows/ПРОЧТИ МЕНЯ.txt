WINTER CHAT SERVER — сервер мессенджера для тебя и друзей
==========================================================

КАК ЗАПУСТИТЬ
1. Распакуй архив в любую постоянную папку (например C:\WinterChatServer).
2. Дважды щёлкни winter-chat-server.exe.
3. Windows может спросить про брандмауэр (два раза: для сервера и для livekit-server) —
   отметь обе галочки (частные и общественные сети) и нажми «Разрешить».
4. Откроется панель в браузере: там адрес сервера и код приглашения.
5. НЕ закрывай чёрное окно — пока оно открыто, сервер работает.

КАК ПОДКЛЮЧИТЬ ДРУЗЕЙ
- В одной сети (один Wi-Fi): друг вводит в приложении адрес «домашняя сеть» из панели.
- Через интернет: открой на роутере порты на этот компьютер:
      8090 TCP  — приложение, чаты, файлы
      7881 TCP  — звонки (запасной путь)
      7882 UDP  — звонки
  и дай друзьям адрес «интернет» из панели.
- Если провайдер не даёт «белый» IP — поставьте всем бесплатный VPN
  (Tailscale, ZeroTier или Radmin VPN) и используйте его адрес из панели.

АВТОЗАПУСК
- «Автозапуск - включить.bat» — сервер будет запускаться сам при входе в Windows.
- «Автозапуск - выключить.bat» — отменить.

СОВЕТ ДЛЯ НОУТБУКА: в настройках питания запрети сон (и при закрытой крышке),
иначе сервер «уснёт» вместе с ноутбуком.

ДАННЫЕ
Все сообщения, файлы и аккаунты лежат в папке winter-chat-data рядом с программой.
Резервная копия = скопировать эту папку (при выключенном сервере).
