# Winter Chat

Мессенджер для своей компании, похожий на Discord: личные чаты и группы, фото, видео и файлы, голосовые и видеозвонки с демонстрацией экрана. Работает на Windows, Linux и Android. Входит в семейство приложений Winter Hub.

Всё хранится на **твоём** компьютере: на нём запускается программа-сервер, а друзья подключаются к ней из приложения.

## Быстрый старт

1. На ноутбуке-сервере распакуй архив сервера и запусти `winter-chat-server` (на Windows — двойной щелчок по `winter-chat-server.exe`).
2. Откроется панель `http://localhost:8090`: на ней будут **адрес сервера** и **код приглашения**.
3. В приложении нажми «Регистрация», введи адрес, придумай логин и пароль, введи код приглашения.
4. Друзьям через интернет: открой на роутере порты **8090 TCP**, **7881 TCP**, **7882 UDP** на ноутбук. Если у провайдера нет «белого» IP, используйте Tailscale, ZeroTier или Radmin VPN.

## Безопасность

- Регистрация только по **коду приглашения** вида `SNOW-7K3P-9QXA`. Старые короткие коды (`SNOW-1234`) при запуске новой версии сервера автоматически заменяются на длинные — новый код смотри в панели.
- Включено ограничение частоты запросов: подобрать пароль или код приглашения перебором через интернет не получится.
- Панель `http://localhost:8090` открывается только на самом компьютере-сервере. Чужие сайты в браузере, туннели (ngrok, cloudflared) и подмена адреса к ней доступа не получают.

## Как устроено

- `server/` — сервер на Go: [PocketBase](https://pocketbase.io) (аккаунты, чаты, файлы, обновления в реальном времени) + [LiveKit](https://livekit.io) (звонки, камера, демонстрация экрана), всё в одной папке.
- `lib/` — приложение на Flutter (Dart).
- Сборку делает GitHub Actions: при каждом изменении собираются все файлы, а сервер проходит автоматическую проверку.
